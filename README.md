# Fluxo

Página de descarga de **Fluxo**, la app de finanzas personales y de negocio hecha para Venezuela.

**Descárgala aquí:** https://jagpromax.github.io/fluxo/

El APK de cada versión está en [Releases](https://github.com/JAGPROMAX/fluxo/releases), firmado con la llave oficial de Fluxo. Compara la huella SHA-256 publicada en la página antes de instalar.
